# Agent Helm design system

Authority: the Enterprise-D bridge set from Star Trek: The Next Generation. The bridge must read as that set from the captain chair within seconds.

## Palette

- Wall panels: warm beige #9a8a7a and tan #c99a6b.
- Carpet: brown #4a3f3a. Raised deck trim: #6b5a4e.
- Tactical rail: wood tone #8a6a4a.
- Consoles: deep blue-grey #3a3f52 with near-black LCARS fields #0b0e1a and #151a30.
- LCARS accents: amber #f2a541, peach #e8b48a, tan #c99a6b, lavender-blue #7aa2c9, alert red #c95f4a.
- Text on panels: warm off-white #f3e9d7, dim text #9b917f.

Colour comes from set tones and LCARS panels. No generic glow gradients, no purple-blue hero treatment.

## Layout

Oval plan. Main viewer centred forward, helm and ops in the forward pit, command chairs on the raised centre deck, horseshoe tactical rail behind the captain, curved aft wall with science and engineering stations and two turbolift doors, ramps on both sides between pit and aft deck.

## Panels

LCARS panels carry a station name, labelled segment blocks, and a status column. Canvas textures at 1024px wide stay readable at arm length. Every screen header reads AGENT HELM.

## Light

Warm and soft like set lighting: ambient warmth, one soft key, emissive LCARS, brighter main viewer. Starfield visible through the viewer frame when no page content replaces it.
